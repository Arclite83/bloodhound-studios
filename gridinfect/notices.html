UNRESOLVED

The following could not be determined from the build and are deliberately not guessed at. Resolve each one before or shortly after store submission.

Licence identifier for Google's binary ad and consent SDKs. Google Mobile Ads for Android and iOS, and the User Messaging Platform for Android and iOS, are shipped as compiled binaries under Google's developer terms rather than a named open-source licence. Google publishes no SPDX identifier for them, and the binaries were not unpacked to read any embedded notice file. Their own bundled third-party notices are surfaced by the SDK at runtime on Android via Google Play services' open-source notices screen.

Google Play Billing Library version and licence. Unity In-App Purchasing bundles the Google Play Billing Library in its Android provider. The version resolves when the Android build runs and is not recorded in the project manifests, so neither the version nor its licence terms could be read from the source tree.

Per-package Unity licence files. The Unity packages above were read from the project's package lock file, which records versions but not licences. The individual licence file inside each package was not available in the source tree at generation time, so "Unity Companion License" above is Unity's general policy for these packages rather than a per-package reading.
